# Student Information System

## Objective
To show how a C `struct` can store different kinds of data (text and numbers) for one student, and to display it. The project has a C console program and a web version.

## Features
- Takes student name, department, semester, email and roll number
- Prints all details in a clean format
- Web version with form checks (empty fields, valid email, valid roll number)
- Shows a list of students added in the session

## Technologies Used
- C language (`struct`, arrays, `scanf`, `printf`)
- HTML, CSS, JavaScript (web version)
- GitHub (code) and Vercel/Netlify (live site)

## Files
- `Project.c` : original C program
- `index.html` : website version

## How to Compile and Run the C Program
```bash
gcc Project.c -o project
./project          # on Windows: project.exe
```

## How to Run the Website
Open `index.html` in any browser.
